## P1 — 本周待办

### #3 Episode 过期淘汰 🟡

**问题**：Episode 没有时间维度的淘汰机制。旧的 Episode 即使环境变了也可能被匹配到。

**方案**：

| 时间 | 操作 |
|------|------|
| ≥90天未检索使用 | ACTIVE → archived=true，降低 stability |
| ≥180天 | 删除或移入冷存储 |
| archived 被再次匹配并成功 | 重置为 ACTIVE + 更新 last_used |

**改动点**：
- `Episode` 新增 `lastUsedAt` 字段
- `EpisodeCacheService` 新增 `@Scheduled` 淘汰任务（每周凌晨）
- `findSimilarEpisode()` 命中时更新 `lastUsedAt`
