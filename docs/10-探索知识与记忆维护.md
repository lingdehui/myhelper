# 10 - 探索知识与记忆维护

## 1. 概述

自主探索引擎通过离线运行探索任务产生 `KnowledgeSnippet`（知识片段），需要持久化到 Qdrant + Neo4j，并在后续任务规划和执行中被检索复用。同时通过 `MemoryMaintenanceService` 定期维护记忆容量。

---

## 2. KnowledgeSnippet 数据结构

### 2.1 数据模型

**文件位置**：`src/main/java/com/example/desktopbrain/exploration/KnowledgeSnippet.java`

```java
public record KnowledgeSnippet(
    String id,              // UUID，即 Qdrant point ID
    String title,           // 知识点标题（30 字内）
    String content,         // 知识点内容（500 字内，AI 生成）
    String sourceType,      // autonomous_exploration | user_task | web_research
    String sourceEpisodeId, // 来源 Episode ID（可追溯）
    int usageCount,         // 被引用次数
    long createdAt,         // 创建时间戳 (ms)
    long lastUsedAt         // 最后被使用时间戳 (ms，0=未使用)
)
```

**工厂方法**：`KnowledgeSnippet.create(id, title, content, sourceType, sourceEpisodeId)` 自动填充 `usageCount=0`, `createdAt=now`, `lastUsedAt=0`。

### 2.2 来源类型

| sourceType | 说明 | 触发场景 |
|------------|------|----------|
| `autonomous_exploration` | 自主探索引擎产生 | @Scheduled 空闲探索 / AI 手动触发 |
| `user_task` | 用户任务成功经验 | 用户执行任务后 reflectSuccess 提取关键知识 |
| `web_research` | 网络搜索获取 | web_research 探索方法查阅到新文档/技巧 |

## 3. 持久化设计

### 3.1 Qdrant 集合

| 属性 | 值 |
|------|-----|
| 集合名 | `knowledge-snippets` |
| 向量维度 | 768（nomic-embed-text） |
| 距离度量 | Cosine |
| 内容向量化 | `title + " " + content` |
| Payload | sourceType, sourceEpisodeId, usageCount, createdAt, lastUsedAt, title, content |

**初始化**：`EpisodeCacheService` 构造函数中通过 `ensureCollectionExists("knowledge-snippets")` 创建。

### 3.2 Neo4j 节点

**标签**：`KnowledgeSnippet`

| 字段 | 类型 | 说明 |
|------|------|------|
| `snippetId` | String | 与 Qdrant point ID 一致 |
| `title` | String | 知识点标题 |
| `content` | String | 知识点内容 |
| `sourceType` | String | 来源类型 |
| `sourceEpisodeId` | String | 来源 Episode ID |
| `usageCount` | int | 引用次数 |
| `createdAt` | long | 创建时间 |
| `lastUsedAt` | long | 最后使用时间 |

**关系**：`(KnowledgeSnippet)-[:DERIVED_FROM]->(:Episode)` — 关联原始 Episode。

### 3.3 写入流程

```
ExplorationExecutor.saveKnowledgeSnippet(assessment, episodeId)
  │
  ├── KnowledgeSnippet.create(uuid, title, content, "autonomous_exploration", episodeId)
  │
  ├── [Qdrant] embed(title + content) → upsert to knowledge-snippets collection
  │
  ├── [Neo4j] snippetRepository.save(KnowledgeSnippetNode)
  │     └── MERGE (:KnowledgeSnippet {snippetId: ...})
  │
  └── System.out.println("📝 已持久化知识片段: " + snippet.title())
```

### 3.4 检索接口

**KnowledgeSnippetService.search(query, limit)**：

```
用户输入 → embed(query) → Qdrant search("knowledge-snippets", score_threshold=0.6, top_k=limit)
  → 命中的 Qdrant point
  → 异步更新 lastUsedAt (Qdrant payload + Neo4j)
  → 返回 List<KnowledgeSnippet>
```

## 4. 集成到规划管道

### 4.1 ToolPlanner.plan() 注入

**位置**：`ToolPlanner.plan()` L3 阶段检索

```
ToolPlanner.plan()
  │
  ├── L1: 内存缓存
  ├── L2: Qdrant Episode 向量检索
  ├── ...
  └── L3: AI 工具规划
        │
        ├── embed(userInput)
        ├── searchFailurePatterns(userInput, 3) → 失败警告
        └── KnowledgeSnippetService.search(userInput, 3) ← 新增
              → 格式化为 context 注入 System Prompt:
                "📚 相关知识点: {snippet.title}: {snippet.content}"
```

### 4.2 FailurePatternTool 合并检索

**位置**：`FailurePatternTool.searchFailurePatterns()`

新增参数 `includeKnowledge: boolean`，当为 true 时同时检索 KnowledgeSnippet，返回结果合并展示：

```
📋 发现 2 条失败经验 + 1 条知识点:
⚠️ [相似度: 88%] 目标网页URL不存在...
💡 [相似度: 75%] 百科搜索技巧: 安装软件时先搜索品名+版本号有利于找到最新版...
```

### 4.3 AutonomousExplorationService.buildContext()

将 `knowledgeCount = 0` 替换为 `KnowledgeSnippetService.count()`，让探索引擎感知已有的知识储备。

## 5. MemoryMaintenanceService 记忆维护

### 5.1 概述

**文件位置**：`src/main/java/com/example/desktopbrain/exploration/MemoryMaintenanceService.java`

**触发**：`@Scheduled(cron = "${desktopbrain.memory-maintenance.cron:0 0 4 * * ?}")` — 每日凌晨 4:00

### 5.2 当前实现（基础版）

```
scheduledCleanup()
  ├── 1. calculateUsageRate()
  │     总点数 = episodes + failure-patterns 的点数
  │     占用率 = 总点数 / 100000（上限）
  │
  ├── 2. 占用率 < threshold → 跳过
  │
  └── 3. 占用率 ≥ threshold → 清理
        filter: archived=true AND stability<0.1
        limit: (占用率 - target) * MAX_POINTS
        删除: POST /collections/episodes/points/delete?wait=true
```

### 5.3 待升级（价值评分版）

详见 [11-记忆价值评分系统.md](file:///d:/project/myhelper/docs/11-记忆价值评分系统.md)。

当前清理语句是最简版：
```java
Map<String, Object> filter = Map.of("must", List.of(
    Map.of("key", "archived", "match", Map.of("value", true)),
    Map.of("key", "stability", "range", Map.of("lt", 0.1))
));
```

**升级方向**：
- 多维价值评分 `w1*recency + w2*usage + w3*userProduced + w4*dependency`

- `protectMemory(id)` AI 白名单工具
- AI 审核清理摘要报告

## 6. 配置项

**文件**：`src/main/resources/config/desktopbrain-exploration.yml`

```yaml
desktopbrain:
  memory-maintenance:
    enabled: true
    cron: 0 0 4 * * ?                 # 凌晨 4 点执行
    threshold: 0.7                     # 占用率阈值（触发清理）
    target: 0.5                        # 清理后目标占用率
    weights:                           # 价值评分权重（预留）
      recency: 0.3                     # 时间新鲜度
      usage: 0.3                       # 使用频率
      user-produced: 0.25              # 用户直接产出
      dependency: 0.15                 # 被依赖关系
    retention-rules:                   # 按来源保留天数（预留）
      user-task: 365                   # 用户任务
      autonomous-exploration: 90       # 自主探索
      failure-pattern: 180             # 失败模式
```

## 7. 关键决策记录

| 决策 | 内容 |
|------|------|
| 存储引擎 | Qdrant（向量检索）+ Neo4j（关系追溯）双写 |
| 向量化范围 | title + content 拼接后 embed |
| 检索阈值 | score_threshold ≥ 0.6（低于 Episode 的 0.65，因为知识片段更通用） |
| 异步策略 | 写入异步（不阻塞探索执行），检索同步（规划阶段必须等待） |
| 清理保留 | archived 且 stability≥0.3 的数据保留不删（即使超过 retention 天数也保留），人工审核后再定 |
