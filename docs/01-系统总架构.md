# 01 - 系统总架构

## 1. 项目愿景

**DesktopBrain** 是一个本地化、多模态的个人 AI 智能助手，目标是实现 Jarvis 级别能力：

- 🗣️ **自然语音交互** — 支持唤醒、对话、打断、声纹识别
- 🧠 **持久化记忆** — 能记住你的偏好、习惯、历史对话
- 🛠️ **自主执行任务** — 查资料、装软件、控智能家居、操作屏幕
- 📚 **自我学习进化** — 从成功执行中提取经验，自动优化执行计划
- 🏠 **设备全连接** — 通过 MCP 协议统一管理所有智能设备

## 5. 核心设计理念

### 5.1 三层执行流

```
用户输入
  │
  ▼
┌─────────────────────────────────┐
│  Layer 1: Episode 向量匹配     │ ← 优先：直接复用历史成功经验
│  Qdrant 搜索相似请求 → 匹配计划 │
└─────────────────────────────────┘
  │ 匹配成功                │ 匹配失败
  ▼                         ▼
┌─────────────────┐   ┌─────────────────────────┐
│ 直接执行计划    │   │  Layer 2: AI 工具规划    │ ← 次选：AI 选工具
│ (稳定度高时)    │   │  分类查询 → AI 选工具   │
└─────────────────┘   └─────────────────────────┘
  │                          │ 规划成功
  ▼                          ▼
┌─────────────────┐   ┌─────────────────────────┐
│ 执行 + 反馈     │   │  Layer 3: AI 自由对话   │ ← 兜底：全工具
│ 更新 Episode    │   │  全部工具 → AI 自由选择 │
└─────────────────┘   └─────────────────────────┘
```

### 5.2 渐进式智能

```
1. 每次成功执行 → 自动创建 Episode 存入 Qdrant
2. 重复任务 → 命中 Episode 缓存，跳过 AI 规划（省 Token）
3. 稳定度达阈值 → 自动脚本化，零 Token 消耗
4. 通用步骤提取 → 形成可复用的原子计划
5. 失败归因 → 自动分段或重新规划
```

### 5.3 自然交互

```
用户说话
  │
  ├─ 唤醒词检测（模糊监听）
  │
  ├─ VAD 分段 → ASR → SpeechAssembler 拼接
  │
  ├─ 声纹验证（可选，已注册用户）
  │
  ├─ AI 执行中可自然打断
  │   └─ 打断内容作为新指令
  │
  ├─ 补充信息流程
  │   └─ AI 执行中用户补充 → 确认 → 重调
  │
  └─ TTS 异步播放 + 继续监听
```

## 7. 快速开始

### 7.1 前置条件

```bash
# 1. 启动 Docker 服务
docker compose up -d

# 2. 启动 Ollama
ollama serve &
ollama pull nomic-embed-text

# 3. 启动应用
mvn spring-boot:run
```
