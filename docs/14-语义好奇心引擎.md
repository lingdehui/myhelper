## 1. 概述

### 1.1 这是什么

从文本流中自动发现 **AI 不认识的词汇/概念**，搜索学习后存入知识图谱。

```
用户说："帮我用 Selenium 写个爬虫"
               │
               ▼
        AI 不认识 "Selenium"
               │
               ▼
        自动搜索 "Selenium 是什么"
               │
               ▼
        学习结果存入 Neo4j/Qdrant
               │
               ▼
        下次用户再提 Selenium → AI 已知道
```

### 1.2 为什么值得做

| 维度 | 说明 |
|------|------|
| **独立** | 不依赖探索引擎是否成功，不调用任何桌面工具 |
| **只走本地模型** | qwen3:30b 做 NER + 搜索，不走 DeepSeek API |
| **异步不阻塞** | 文本流旁路异步处理，不影响主对话 |
| **持续积累** | 每学一个概念都是永久资产，知识图谱自动增长 |
| **ROI 高** | 5 个类 + 2 Prompt，投入小，产出持续 |

### 1.3 适用场景

| 场景 | 示例 |
|------|------|
| 用户提到新技术名词 | "用 gRPC 通信" → AI 学 gRPC |
| 工具返回未知错误 | "Error: OOM killed" → AI 学 OOM |
| 浏览网页遇到术语 | 页面含 "WebSocket handshake" → AI 学 WebSocket |
| 系统日志陌生关键词 | "ACPI BIOS Error" → AI 学 ACPI |

## 2. 核心流程（完整闭环）

```
   ┌──────────── 学习路径（异步） ────────────┐
   │                                          │
   ▼                                          │
 文本流                                       │
   │                                          │
   ├──→ NER 抽取未知概念                       │
   │       │                                  │
   │       ▼                                  │
   │   过滤已知（查 Qdrant）                    │
   │       │                                  │
   │       ▼                                  │
   │   评分排序 → 生成搜索任务                   │
   │       │                                  │
   │       ▼                                  │
   │   执行搜索 → 学到的知识                    │
   │       │                                  │
   │       ▼                                  │
   │   embed 存入 Qdrant knowledge ─────────────┘
   │
   │
   └────── 检索路径（同步） ────────────┐
                                        │
 用户下次说话                             │
   │                                    │
   ▼                                    │
 embed(用户输入) → Qdrant knowledge 检索  │
   │                top-3 相关知识 ←─────┘
   │
   ▼
 注入 prompt: "[已知知识] ..."
   │
   ▼
 AI 带着知识回复
```

**两个路径**：
- **学习路径**（异步）：文本流 → 发现未知 → 搜索 → 存 Qdrant
- **检索路径**（同步）：每次对话前查 Qdrant → 注入 prompt → AI 已知晓

## 3. 核心组件

### 3.1 UnknownConceptDetector

**包路径**：`com.example.myhelper.curiosity.UnknownConceptDetector`

```java
@Service
public class UnknownConceptDetector {

    /** 从文本中检测未知概念（异步调用，不阻塞主流程） */
    public List<UnknownConcept> detect(String text, TextSource source);

    /** 批量检测（长文本分段，每段 ≤500 字） */
    public List<UnknownConcept> detectBatch(List<String> segments, TextSource source);
}

// 数据结构
public record UnknownConcept(
    String id,
    String name,                  // 概念名称
    String contextText,           // 上下文（前后各 100 字）
    TextSource source,            // USER_INPUT / TOOL_RESULT / WEB_CONTENT / SYSTEM_LOG
    double noveltyScore,          // 新颖性 0~1，越陌生越高
    double relevanceScore,        // 与当前任务关联度
    Instant discoveredAt
) {}
```

**实现逻辑**：

| Step | 内容 |
|------|------|
| 1. NER | Prompt → qwen3:30b 抽取名词短语/专有名词/缩写/技术术语/错误码 |
| 2. 已知度检查 | 对概念名做 embedding → Qdrant `knowledge` 向量相似度 `> 0.70` → 已知，跳过 |
| 3. 噪音过滤 | 纯数字/符号、长度 < 2、常见停用词 → 丢弃 |
| 4. 新颖性评分 | `1.0 - Qdrant最大相似度`

**Prompt**（`prompts/curiosity-ner.txt`）：
```
从以下文本中抽取值得关注的名词短语、专有名词、缩写、技术术语。

文本：{text}

严格 JSON 输出：
{
  "entities": [
    {"name": "实体名", "type": "TECHNICAL_TERM/ERROR_CODE/ABBREVIATION/OTHER",
     "description": "基于上下文的初步猜测"}
  ]
}
```

**配置**：
```yaml
curiosity:
  detection:
    similarity-threshold: 0.70     # Qdrant 向量相似度 ≥ 此值视为已知
    min-concept-length: 2
    max-per-text: 20
    llm-timeout-ms: 3000
```

### 3.2 ConceptCuriosityEvaluator

**包路径**：`com.example.myhelper.curiosity.ConceptCuriosityEvaluator`

```java
@Service
public class ConceptCuriosityEvaluator {

    /** 评估 + 去重 + 排序，返回值得探索的概念列表 */
    public List<ScoredConcept> evaluate(List<UnknownConcept> concepts);

    /** 近期是否已探索过 */
    public boolean wasRecentlyExplored(String conceptName, Duration window);
}

public record ScoredConcept(
    UnknownConcept concept,
    double curiosityScore,       // 0~10
    boolean isHighPriority       // > 7
) {}
```

**评分算法**：

| 维度 | 权重 | 说明 |
|------|:--:|------|
| 新颖性 | 40% | `noveltyScore × 4.0` |
| 关联度 | 30% | `relevanceScore × 3.0` |
| 来源加成 | 20% | USER_INPUT +2.0 / SYSTEM_LOG +1.5 / TOOL_RESULT +1.0 / WEB +0.5 |
| 类型加成 | 10% | 错误码 +1.0 / 文件路径 +0.5 |

### 3.3 CuriosityTaskGenerator

**包路径**：`com.example.myhelper.curiosity.CuriosityTaskGenerator`

```java
@Service
public class CuriosityTaskGenerator {

    /** 为高价值概念生成探索任务 */
    public CuriosityTask generate(ScoredConcept scored);

    /** 合并相关概念为一个批量任务 */

public class CuriosityTask {

    String contextText;            // 发现上下文
```

```
严格 JSON 输出：
{
  "search_query": "精确的搜索问题",
  "suggested_tools": ["工具名"],
  "knowledge_summary": "预期学到的知识摘要（≤100字）"
```

## 4. 集成点

### 4.1 学习路径（3 处异步挂载）

| 触发点 | 位置 | 改动 |
|--------|------|:--:|
| 用户说完话 | `TurnProcessor.process()` 入口 | +1 行 |
| 工具返回结果 | `LoggingToolCallback.onSuccess()` | +1 行 |
| AI 回复输出 | `SpeechAssembler` 完成后 | +1 行 |

```java
// 三处都是同一行:
CompletableFuture.runAsync(() -> detector.detect(text, source));
```

### 4.2 存储：只用 Qdrant

| 操作 | 方式 |
|------|------|
| 写入 | embedding(知识摘要) → Qdrant `knowledge` collection upsert |
| 已知度检查 | embedding(概念名) → Qdrant `knowledge` 向量相似度 |
| 集合初始化 | 应用启动时幂等创建，768维 Cosine |

collection `knowledge` 字段：
- `text` — 知识摘要（如 "gRPC 是 Google 的高性能 RPC 框架..."）
- `concept` — 概念名称
- `source` — 来源（user_input / web_search / tool_result）
- `timestamp` — 学习时间

### 4.3 检索路径：KnowledgeInjector（新增）

**这是数据被使用的关键环节。**

```java
@Service
public class KnowledgeInjector {

    /**
     * 在构造 AI prompt 前调用。
     * 对 userInput 做 embedding → 查 Qdrant knowledge top-3 → 注入 prompt
     */
    public String injectKnowledge(String userInput, String originalPrompt) {
        List<String> relevant = searchKnowledge(userInput, 3);
        if (relevant.isEmpty()) return originalPrompt;

        return "[已知知识] " + String.join(" | ", relevant)
                + "\n\n" + originalPrompt;
    }
}
```

**调用位置**：`TurnProcessor.process()` 或 `ToolPlanner.plan()` 中，构造 prompt 前插入一行。

### 4.4 需要扩展的服务

| 现有服务 | 新增方法 | 改动量 |
|----------|---------|:--:|
| `EmbeddingService` | 已有 `embed()`，无需改动 | 0 |
| `QdrantConfig` | 新增 `knowledge` collection 初始化 | ~10 行 |

> 不再需要改动 `KnowledgeGraphService` 和 `VectorMemoryService`。
