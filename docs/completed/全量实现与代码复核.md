## 2. 实际调用及数据流

1. **任务运行。** 执行根任务前查外部恢复快照，正常新根才做入口检索。模型规划请求由 `AgentCallerPlanner` 组装，`AgentCaller` 只完成一次调用。每个 PLAN 后重新查总目标和各步骤。已选能力仍经过适用判断，固定能力中的工具按本次绑定后的实际参数评分。后继只依赖成功的前驱，动作事实与验收结论分别回报。待输入、未知效果和外部等待有独立结果。 [循环源码](../../src/main/java/com/example/myhelper/orchestration/AgentOrchestrator.java)
2. **直执与统计。** 缺失、低分或查询失败回退模型。默认评分严格大于 0.85，普通工具另要求至少五次成功，可信工具仅免次数门限。估计值结合先验与执行事实，确认环境失败从分母扣除。精确参数有已验收证据可以直接利用，扩大到已有批准范围时由范围模型判断。即使无需重新规划，范围判断本身仍可能发起单次模型请求。 [可靠度门限](../../src/main/java/com/example/myhelper/orchestration/ToolReliabilityGate.java) · [范围判断](../../src/main/java/com/example/myhelper/skill/RecordedToolReliability.java)
3. **归档与技能。** 循环在工作实际收束后提交结束、图和缺口。若独立记录实现持久化并通知监听器，技能后台读取该归档，把宿主派发的 ToolRef、实际返回与验收配成样本，再处理固化待办。模型离线时原参数仍可保存。候选发布与这条自动消费链可分别验证，当前缺少生产归档来源和完整的子图分流 Store。 [收尾接线](../../src/main/java/com/example/myhelper/orchestration/RunRecordAccess.java) · [归档监听](../../src/main/java/com/example/myhelper/skill/ArchivedSkillProcessing.java)
4. **发布与检索。** 已批准候选固定发布身份、计划与向量载荷，写入权威与索引目标。Qdrant 召回返回带 ID 和修订的实体候选，经权威库核对发布状态、当前修订和计划定义。两库选择由业务装配显式提供。公共向量空间依赖同一个嵌入组件及一致的摘要、维数。 [发布仓储](../../src/main/java/com/example/myhelper/skill/StoredSkillRepository.java) · [查询仓储](../../src/main/java/com/example/myhelper/capability/QdrantCapabilityRepository.java)
