## 2. Neo4j 图谱设计

### 2.1 节点类型（Label + 属性）

| Label | 属性 | 示例 |
|-------|------|------|
| `Concept` | name, pos(词性), category(类别), confidence, sourceId, senseId(消歧) | 苹果{名词,食物,0.9,SRC1,sense_1} |
| `Scene` | name, description | 渡劫现场 |
| `Emotion` | name, valence(正/负), intensity(0-1) | 恐惧{负,0.8} |
| `Episode` | goal, result, weight, reuseCount | 批量续写{成功,+2,5} |
| `Source` | name, trust(可信度) | 百度百科{0.9} |

### 2.2 边类型（必须分类，抽象与联想分开）

| 边 | 语义 | 用途 |
|----|------|------|
| `[is_a]` | 上位/抽象（苹果→水果→食物） | **抽象计算只沿它爬**，且两端 category 必须相同 |
| `[assoc]` | 联想/共现（渡劫↔心魔） | 跨类别关联，不参与抽象 |
| `[has_emotion]` | 场景→情绪（渡劫→恐惧） | 情绪挂场景节点，不直接挂物体 |
| `[leads_to]` | 行为→结果（硬扛→走火入魔） | **趋避奖惩的预测基础**，奖惩调整它的权重 |
| `[reused]` | Episode 被复用计数 | 奖惩落点（行为层） |

### 2.3 分层

```
通用层   ← HowNet 上位词树 + 大连理工情感库 + jieba 词性（一次性导入）
领域层   ← 你的领域词（心魔/渡劫/道心…），补连到通用层
经验层   ← Episode（行为-结果，跑出来的）
```

### 2.4 关键 Cypher

```cypher
-- 抽象爬升：从苹果沿 is_a 往上
MATCH (c:Concept {name:'苹果'})-[:is_a*1..3]->(p)
RETURN p.name, p.category

-- 趋避预测：这个行为会导致什么
MATCH (b:Concept {name:'硬扛'})-[:leads_to]->(r)-[:has_emotion]->(e)
RETURN r.name, e.name, e.valence

-- 奖惩：成功的经验复用链
MATCH (ep:Episode {result:'success'})-[r:reused]->()
SET ep.weight = ep.weight + 1, r.count = r.count + 1
```

## 3. Qdrant 向量设计

### 3.1 集合规划（建议新增 `semantic-brain`）

| 集合 | 向量内容 | Payload | 用途 |
|------|---------|---------|------|
| `concepts` | 概念/词义的 embedding | name, pos, category, confidence, graphId(←Neo4j 节点id) | 陌生度计算、语义检索 |
| `scenes` | 场景描述 embedding | name, graphId | 场景识别 |
| `episodes`(已有) | 行为经验 embedding | goal, result, weight | 行为匹配 |

### 3.2 向量怎么来

- 概念/场景：用现有 `EmbeddingService`（bge-m3，1024 维，兼容）
- 检索时同时返回 `graphId` → 跳回 Neo4j 取关系 → 实现"向量找相似 + 图谱看关系"

### 3.3 一致性问题（双库同步）

- **约定**：Neo4j 节点 id 作为唯一 `graphId`，写入 Qdrant payload。
- 写入顺序：先建 Neo4j 节点 → 再存 Qdrant 向量（携带 graphId）。
- 删除：以 Neo4j 为准，Qdrant 定期清理无对应节点的向量。

## 4. 双库协作流程

### 4.1 好奇心入库（学习）

```
新词/新场景
  → ① 陌生度: concepts 集合最近邻距离
  → ② 相关度: Neo4j 一跳关联
  → ③ 区间: 中等陌生(0.2~0.9) 且 相关 → 触发外搜(百度/必应)
  → ④ 质检四道闸: 来源可信度 / 长度≥N / 含实体 / 向量相似>0.95去重
  → ⑤ 打标: jieba词性 + HowNet类别 + 情感库情绪
  → ⑥ 入库: Neo4j节点(graphId) + Qdrant向量(graphId)
```

### 4.2 查询回答（趋避决策）

```
问题
  → 向量召回: concepts 找 topK 相关概念(graphId)
  → 图谱扩展: 沿 is_a 抽象 + assoc 联想 + leads_to 预测 + has_emotion 情绪
  → 组装上下文 → 交给 LLM 生成回答
```

## 7. 一句话总结

**你有：** 两个库、向量服务、奖惩信号源（Reflect）、经验沉淀机制。
**你缺：** 图谱通用语义层（导入器）+ 好奇心系统（陌生度/外搜/质检）+ 趋避闭环（成功加权 + leads_to 边）。
**顺序：** 先奖惩闭环（改现有代码）→ 再图谱 schema（导入数据）→ 最后好奇心（新组件）。
