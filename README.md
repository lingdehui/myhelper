# myhelper — 一个能在自己电脑上自己进化、自己探索的 AI 桌面助手

> 说"那个谁"，它就干活。
>
> 不用联网，自己学用新软件，错了自己总结教训，重复的事自动脚本化——**零 Token 消耗**。

### AI 自己写工具

现有工具不够？系统自动生成 Java 工具类 → 编译 → 动态加载。同一工具连续 3 次失败自动删除，防止垃圾代码堆积。工具列表按分类精简 Token，AI 规划更快更准。

## 架构

```
你说 "那个谁，帮我装个 Python" ──→ 语音唤醒 ──→ ASR 识别 ──→ AI 规划 ──→ 控制屏幕操作 ──→ 安装完成
                    ↑                                                                      ↓
                                                                                    记录成功经验
                    ↑                                                                      ↓
               ┌──────────── 三层缓存 ────────────┐ ← 下次直接执行（零 AI 调用）
               │ L1: 内存缓存    ~0ms              │
               │ L2: Qdrant 向量检索   ~200ms       │
               │ L3: AI 重新规划    ~3s             │
               └──────────────────────────────────┘
```

## 核心亮点

### 三层缓存 — 记住了，就零成本重复
```
第一次: "帮我查天气" → Qdrant 向量记忆
第二次: "再查一下天气" → 内存命中 (~0ms), 直接回放工具调用
第三次: "查天气" → 连续 5 次成功 → 可脚本化 (canScript=true)
                 → 零 Token 消耗，纯 Java 按步执行
```

### Episode 经验闭环 — 越用越聪明

| 阶段 | 内容 |
|------|------|
| 成功 | AI 反思 30 字成功经验 → 存入 Qdrant → 下次自动复用 |
| 失败 | 滑动窗口聚合失败模式 → 同步 Neo4j + Qdrant |
| 归纳 | 每天凌晨 3 点跨案例提炼规则 → 注入 AI 规划 prompt |
| ATOMIC | ≥3 个复合任务共用同一子步骤 → 自动提取通用原子操作 |

### 自主探索引擎 — 自学没用过的能力

- **能力清单** — 启动时自动扫描全部工具，动态生成难度分级的候选任务（⭐⭐⭐~⭐⭐⭐⭐）
- **渐进式** — 基础能力未覆盖时禁止跳级学习
- **防死循环** — 同一目标连续失败 ≥2 次 → 自动冻结 24 小时
- **双语工具搜索** — 中文搜不到自动英文兜底，AI 不会再幻觉不存在的工具
- **@GeneratedTool 监控** — 同一生成工具同一原因失败 ≥3 次 → 自动删除源码 + 卸载

### 完整的失败处理

```
工具失败 → AI 归因（计划问题/环境问题）
               │
       计划问题 → 重规划     环境问题 → 分段继续
               │                       │
        三次同一失败 → FailurePattern    │
               │                       │
        凌晨 3 点 → Rule 归纳 → 注入 prompt：下次直接避坑
```

## 快速开始

> **不想下载 18GB 本地模型？**  
> 在 `application.yml` 中设置 `desktopbrain.exploration.enabled: false`，所有 AI 调用走 DeepSeek API，日常使用约 ¥1-2/天。

```bash
# 1. 启动基础设施 (Neo4j + Qdrant + Home Assistant)
docker compose up -d

# 2. 启动 Ollama + 拉模型
ollama serve &
ollama pull nomic-embed-text    # 嵌入模型 (274MB)
ollama pull qwen3:30b           # 本地模型 (18GB)

# 3. 编译运行
mvn compile -DskipTests
mvn spring-boot:run

# 4. 验证
# Neo4j:  http://localhost:7474
# Qdrant: http://localhost:6333
# Ollama: http://localhost:11434
# 应用:    http://localhost:8082
```
