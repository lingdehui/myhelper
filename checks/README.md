# 独立验证资料

按用户 2026-11-11 要求，从主工程的 `src/test` 移到此处，业务源码只放在 `src/main`。

- `java/`：原有 8 个测试/检查类，内容原样保留。
- `resources/`：原有规划请求合同快照。
- `build/`：本机检查的编译产物，不提交版本库。

本目录是独立保存的验证资料，不是应用启动入口，也没有注册为根工程默认的 Maven 测试源码目录。根工程的默认 `test`/`test-compile` 不再读取这里的源码；后续如果明确需要运行，应显式使用本目录，不能把测试类重新塞回业务源码。此前文档中的验证结果保留为历史记录。

真正的任务组件入口为 `AgentOrchestrator.submit(Request)`；当前仍缺应用级 main、真实组件装配和用户输入入口。此处使用替身组装的 Harness 不能作为正式启动方式。
