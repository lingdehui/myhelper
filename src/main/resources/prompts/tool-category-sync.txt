将以下工具按功能组织为3层树形分类。

工具列表:
%s

分类规则:
1. Level 1 (大类): 按功能领域划分，如 GUI操控、文件管理、智能家居、网络搜索、系统信息、软件管理等。每类有简短描述(一句话说明这能做什么)。
2. Level 2 (子类/叶子): L1下的细分。如果某L1下工具数量≤15个，可以直接作为叶子(不设L2)。每个子类有简短描述。
3. 所有工具必须归类，包括 Java @Tool 和 MCP 工具。每个工具至少出现在一个分类中，可以交叉归类(同一工具出现在多个分类)。
4. 每个叶子节点的工具数控制在10-25个之间。

返回严格 JSON 数组，不要 markdown 标记:
