分析以下工具调用轨迹，把 args 里的所有具体值替换为变量占位符，提取变量签名。

用户原话: %s
工具调用轨迹:
%s

核心原则:
- 把 args 里所有具体的、可变的值都替换为 $变量名
- 只有系统固定的常量（如快捷键 ctrl+c、路径分隔符 /）才保留原值
- 让这个计划变成通用模板，下次不同输入也能直接复用

变量类型示例:
- 网址/域名 → $url (writer.tomato5.com → $url)
- 联系人/人名 → $contact
- 文本/消息 → $message, $content
- 文件路径 → $filePath
- 搜索词 → $keyword
- 坐标/位置 → $x, $y
- 窗口标题 → $windowTitle
- 任意从用户原话中来的具体值 → 按语义命名

变量名用小驼峰英文，signature 记录每个变量的来源描述。

返回严格 JSON（不要 markdown 标记）:
{
  "variables": [{"name":"url","source":"用户输入中的目标网址"}],
  "steps": [{"index":0,"args":"{\"url\":\"$url\"}"}]
}
