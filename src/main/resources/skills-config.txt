# 技能配置：根据用户输入关键词自动注入对应规则
# 格式：[技能名] → keywords → instruction

[wechat-friend-chat]
keywords: 给.*发, 发消息, 找.*聊, 好友, 联系人
instruction: 【微信好友聊天规则】
- 切换到微信窗口后，用左侧聊天列表的搜索框（Ctrl+F）找联系人，不要用主界面顶部的全局搜索（会跳到搜一搜/公众号）
- 进入聊天后，点底部输入框，输入内容，Enter 发送
- 用户指定的消息内容就是最终内容，不要修改、不要润色、不要省略
- 每步操作间隔 0.5-1 秒，等界面响应

[wechat-public-account]
keywords: 公众号, 搜一搜, 搜公众号, 小程序, 搜文章
instruction: 【微信搜索规则】
- 切换到微信窗口后，点主界面顶部的搜索框，使用搜一搜功能
- 可以搜索公众号、文章、小程序等
- 这不是找好友发消息，不要用 Ctrl+F 搜聊天列表

[app-launch]
keywords: 打开, 启动, 运行, 调出
instruction: 【应用启动规则】
- 按 Win 键打开开始菜单，输入应用名称，按 Enter 启动
- 如果应用已经在运行，用 Alt+Tab 切换过去
- 启动后等 1-2 秒确认窗口已加载

[file-operations]
keywords: 文件, 文件夹, 目录, 新建, 删除, 移动
instruction: 【文件操作规则】
- 操作前先确认当前路径或窗口
- 删除操作前先确认
- 批量操作时分步执行
