【通用应用数据抓取规则】
- 目标：从任意应用界面抓取结构化数据，保存为 JSON 文件
- 通用步骤：
  1. 切换到目标应用窗口
  2. 确认当前界面显示了需要抓取的数据
  3. 逐屏/逐条获取数据（Ctrl+A全选→Ctrl+C复制，或截图+OCR）
  4. 解析提取的数据（去除空行、重复项、无关信息）
  5. 保存为结构化文件（JSON），文件名用英文，放在项目根目录
  6. 报告统计信息（共X条数据，保存在哪个文件）
- 注意事项：
  - 优先用复制快捷键，OCR 作为没办法选中文字时的后备
  - JSON 文件字段用英文命名，内容保留中文
  - 如果数据量大（超过50条），分批处理并追加写入
